# PDFs en Español

Esta carpeta contiene la versión en **PDF** del libro *Dialéctica Micro-Fractal* en español.  
El PDF ofrece una versión estable del texto para lectura offline, impresión y distribución.

## 📘 Contenido

- **dialectica-microfractal_es.pdf**  
  Última versión oficial del texto en español.

## 🔄 Relación con otras versiones

El PDF es una **representación estática**.  
La versión editable se encuentra en:

- `book/es/` (Markdown)  

Las modificaciones deben hacerse en esa carpeta, no sobre el PDF.
