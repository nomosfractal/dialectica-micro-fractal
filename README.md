# Dialéctica Micro-Fractal

Coherencia, agencia y autonomía  
en contextos de colapso y saturación institucional

</div>

---

Este repositorio contiene materiales conceptuales y prácticos relacionados con lo que aquí se denomina **dialéctica micro-fractal**: una forma de pensar y experimentar la agencia humana cuando las estructuras macro dejan de ofrecer estabilidad, sentido o protección.

No se presenta como teoría total, programa político ni marco normativo.  
No pretende ofrecer soluciones universales ni conducir prácticas ajenas.

Lo que aquí aparece puede leerse como:
- herramientas conceptuales,
- descripciones de patrones observables,
- hipótesis operativas,
- o simples borradores útiles para pensar en contextos específicos.

Su validez no es general, sino **situada**.

Cuando se habla de *microescala*, *coherencia* o *agencia distribuida*, no se alude a una retirada individualista, sino a la posibilidad de sostener prácticas mínimas que no dependen de validación institucional ni de centralización organizativa.

Nada en este repositorio requiere adhesión.  
Todo puede ser usado, modificado, bifurcado o descartado.

### Estructura del repositorio

- Carpeta `book/`: versión del texto en **Markdown**
- Carpeta `pdf/`: versiones exportadas cuando existan

La forma del repositorio no es normativa.  
Es solo una disposición funcional en este momento.
